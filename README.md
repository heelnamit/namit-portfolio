# Namit Mahajan — Personal Portfolio

A hiring-focused portfolio built with **Next.js + React + TypeScript** and styled from the supplied visual direction: dark editorial layout, oversized typography, red accent, project cards, skills grid, approach section and contact CTA.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before publishing

Update the placeholder contact details in `app/page.tsx`:

- `your.email@example.com`
- GitHub `href="#"`
- LinkedIn `href="#"`
- Add a real resume link if desired
- Replace or expand project descriptions with real shipped work

## Netlify

The repo includes `netlify.toml` and the official Netlify Next.js runtime plugin configuration. Push this folder to GitHub, import the repository in Netlify, and deploy. Netlify should detect the Next.js build automatically.

Build command: `npm run build`
